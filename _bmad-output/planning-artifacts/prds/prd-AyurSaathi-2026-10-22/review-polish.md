# Editorial Review: AyurSaathi PRD and addendum

**Purpose/audience read:** This document set exists to help Ravi (sole decision-maker) and downstream BMAD agents (UX, architecture, epics/stories, build) agree on and build an end-to-end prototype of the AyurSaathi patient journey, with testable requirements and an explicit assumptions list.

**Reader type:** humans (Ravi and BMAD downstream agents). **Structure model:** Strategic/Context (Pyramid). **Lenses:** structure, then prose. Content is untouched: no decision, FR/UJ/SM ID, testable consequence or `[ASSUMPTION]` tag is changed by any row below.

**Word counts (word_metrics.py):** prd.md 5,753; addendum.md 299; total 6,052.

**Style notes (preserved):** terse, requirement-style prose; defined terms capitalised as a controlled vocabulary; consistent FR template (statement, "Consequences (testable)"); UJ template (Persona/Entry/Path/Climax/Resolution/Edge); inline tags in backticks. Stated style is deliberate, so only drift from it is flagged.
