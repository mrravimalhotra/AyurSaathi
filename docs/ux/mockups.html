Ayurveda Journey App: key screens

Twelve screens from the blueprint, grouped as: first set (patient list, onboarding, record, arrival, daily check-in), then more for Care, then Departure and Continuity. They follow the decisions made so far and mark proposals as questions at the end of each screen.

These are pictures, not a working app. Every name, flight and number is invented dummy data.
